# Hypernet

Sebastian's network for people who **co-create participatory events** — regional burns, Borderland,
Burning Man scale. Grew out of HYPERSTITION, a four-year art project at a Scandinavian regional
burn; Hypernet preserves those relationships. Not ticketing, not a generic social network: a
directory of people you could build something with, wrapped around a calendar.

I'm helping with the **aesthetic and information architecture**. See
[[2026-09-20 Hypernet Retro Concepts]].

## The five nouns

- **Node / person** — a user described by skills (`SOUND/DJING`) and cities
- **Event** — a dated gathering, public or private, with a host
- **Event Horizon** — a named, published, followable list of events. *Like a Spotify playlist.*
  This is the load-bearing idea; nothing else has it
- **Cluster / Group** — a camp or crew, with admins and members
- **Call out** — a time-boxed "we need a sound engineer"

Plus group chats, **Worlds** (a public square attached to a big event), and a Feed.

## Core features

From my note: log in and say about yourself · see chats · browse/search events, horizons and
users (going / interested / promote; follow) · create event, horizon, group chat · **customize
the thumbnail square and the row** — users style how their event looks in other people's feeds.

## Aesthetic direction

Hard retro, late-90s/early-2000s desktop computing. Windows showing around. The live v0 is
already paper-white, all-monospace, hairline window frames, bracket buttons
(`[ ENTER THE DESERT ]`), with a sparse "digital desert" of floating person cards.

Tagline: *"Welcome to the digital desert. This place is boring and empty until you make it
otherwise."*
