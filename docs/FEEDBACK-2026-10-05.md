## Interpretation (orchestrator's calls — flag any you disagree with)

- **"Android … dark by default"**: the app has no dark theme; Android Chrome's *auto-darken web pages* is inverting the
  grey/white UI (screens 1–5 show the half-inverted result). Opt out (`color-scheme: only light`) so the app always
  renders as designed, and make calendar events readable regardless.
- **Logged out on a phone** there is no tab bar at all; the preview bar (Join free + Log in) is the only bottom bar,
  and Explore is the one place a visitor browses (search stays). Nothing leads to an empty "You".
- **Laptop left alignment** reverses two 2026-10-04 decisions: Home is no longer centred in the white (every view's
  container starts at the white's left, like Explore), and **opening something never moves the list** — the window
  lies over the list, which keeps its place and size. The view heading's left edge = the white panel's left edge.
- **One Edit**: an Event Horizon (and, for consistency, an event and your profile) has one Edit that holds the title,
  details, picture, colours and who can see it. Share is always Share; there is no Publish button that turns into Share.
- **Colours**: a look is built from one colour, optionally a second (accent) and a third; an algorithm derives the whole
  page (background, surfaces, borders, text, muted text, accent) so text is always readable without the picked colours
  "jumping". The whole page wears it, not only the header band.
- **Call out page = the call out**, full screen, no card-inside-a-page; icon = megaphone. On an event page a call out
  with no replies says "No replies yet" (no reply box there).
- **Real-event pictures**: each real event gets a square picture taken from its own website (logo / og:image / icon).
